# 设计系统 · 设计令牌

> 这一份是**跨配色通用**的部分：角色变量的语义、字号阶梯、间距、组件类。
> 每份稿子实际用哪套配色/字体/疏密，由它自己的设计规范决定（`services/ppt/designSpec.ts`，
> 拼装时覆盖 `:root`）—— 所以这里**不写具体色值、不写具体字族、不写页面内边距**。

## 令牌变量（角色语义，注入 :root）
模板与组件类统一引用以下角色变量，不写死具体色值，因此任意调色板都能套：
```
--c-brand        主色（最大面积强调：角标、标题强调、渐变起点、编号徽章）
--c-brand-deep   主色深版（渐变末端点、hover、下划线）
--c-accent       点缀色（第二色：kicker、次强调、渐变终点）
--c-accent-deep  点缀色深版
--c-bg           页面底色（浅）
--c-bg-alt       区块/卡片底（浅，可带微色相）
--c-ink          正文
--c-ink-deep     标题
--c-ink-soft     次要/水印
--c-card         卡片底
--c-hairline     描边
--mask-rgb       全幅背景遮罩用的底色 RGB（= --c-bg 的 rgb，透明度梯度由 CSS 控制）
--mask-rgb-alt    cool 页遮罩底色 RGB（= --c-bg-alt 的 rgb）
```

**硬约束**：所有底色明度 ≥ `#EBF6FC`（浅色无暗黑）；正文/标题对比度达标（AA）。

## 调色板 / 字体 / 疏密的实际取值
这三样是**每份稿子自己选的**（配色 / 字体 / 疏密三档，见 `services/ppt/designSpec.ts`），
由拼装时覆盖 `:root` 生效，本文件**不再列具体色值**。

> 这里以前列着五套配色的具体色值和一套「按行业推导配色」的规则，已经删掉：那些 id 被代码里
> 那份占了（同一个 id 在两边是两套颜色），而这一整段是**原样发给模型的** —— 它会照表把色值
> 写死在 inline style 里，那一页看起来完全正常，只是换配色那天它一个人不跟着变。
> 要加一套配色就加在 `designSpec.ts` 的 `PALETTES` 里（有测试盯着「20 个角色变量给齐了没有」）。

## 字体
- 标题/企业名/金句用 `var(--serif)`，正文/UI 用 `var(--sans)`。
- **不要写 font-family**：这两个变量的实际字族由这份稿子的规范决定（默认宋体标题 + 黑体正文，
  也可能是全黑体/全宋体）。写死的那一处换字体时不跟着变，而它读起来完全正常。
- 禁止系统字体（Arial/Inter/Roboto）与白底紫渐变滥用方案。

## 字号阶梯（1920×1080 舞台）
- 页标题 54px / 章节封面 72px / 企业名 72px
- 金句 38–44px / 正文 22–24px / kicker 20px / 水印 20px
- 编号徽章 112×112，内部数字 48px

## 间距与圆角
- **页面内边距不要自己写**：`.slide-inner` 的 padding 由这份稿子的疏密档决定（舒展/标准/紧凑三档）。
  写死的那一页在换档之后和别的页对不齐，而两页各自都正常。标题下装饰条 90×6（主色→点缀渐变）
- 卡片圆角 12–14px；图圆角 12px；边框 1px hairline
- 顶部 5px 渐变色带（主色→点缀）
