# L1 · `hero-right-visual`（左 54% 文字 + 右 46% 全高视觉）

> **📄 详情**：design 阶段匹配到 L1 时**必读**。
> **★ 核心原则**：结构是灵魂，颜色/内容不绑死 —— 所有配色只用 `var(--c-*)`。
> **★ CSS 在 `library/template.html` 的公共段里（`.p5-visual` / `.p5-content` / `.quote-card` …），这份 md 不抄一份。**
> 抄一份的话 template 一改这里就在说谎，而模型会照这份写 inline style 去「补」尺寸 ——
> 出来是一页尺寸对不上（图宽 46% 而文字按 54% 排、两者中间叠一块）的正常幻灯片，一处都不报错。

---

## 一、结构速览

- **比例**：16:9 横版，左 54% 文字 + 右 46% 全高图（图是绝对定位贴到右边缘的，`.p5-visual::after` 自带左向渐变过渡）
- **是否全幅**：否 —— 文字必须包在 `.slide-inner` 里（`.p5-content` 放在它里面）
- **核心手法**：① 文多图少的 54/46 分屏；② 文字区五层堆叠（英文小标 → 衬线大标 → 色条 → 金句卡 → 正文段）；③ 图不承载信息，只给氛围和右侧配重
- **一页一个主角**：主角是**那句金句**（`.quote-card`），标题是它的引子，正文是它的注脚

---

## 二、结构拆解（左侧文字区，由上至下）

1. **英文小标**（`.kicker`，20px，`var(--c-accent-deep)`）—— 2–4 个英文单词或一个短词组，别写整句
2. **主标题**（`.page-title`，衬线 54px；一行放不下时用 `<br>` 手动断在语义处）
3. **色条**（`.title-bar`）—— 标题和金句之间的呼吸，不带内容
4. **金句卡**（`.quote-card`，衬线 34px，左上角自带一个大引号）
   - 关键词用 `<b>` 包起来就**自动**有橙色高亮底（`.quote-card b`，cool 页自动换成蓝底）。
     **不要自己给它写 `background`** —— 写死的那个底色不跟 palette 变，整份换成墨绿之后就剩这一处是橙的，而它读起来只是「这里强调了一下」。
5. **正文段**（一个 `<p>`，19–21px，`line-height:1.9`，`max-width:640px`）—— 1–2 句，超过 3 句就该拆页
6. **角标**（`.corners` + 四个 `<i class="tl/tr/bl/br">`，可选）—— 只是装饰，内容页想要"版面感"时加

## 三、build-part 结构模板

```html
<section class="slide">
  <!-- 右侧全高视觉（左上角那行模块名由代码统一贴，这里不要写） -->
  <div class="p5-visual" style="background-image:url(/ppt-cases/ph-3x4.svg)" data-img-prompt="这一格要什么图（中文一句话）" data-img-mode="concept"></div>
  <div class="slide-inner">
    <div class="p5-content">
      <div class="kicker">{{英文小标}}</div>
      <h1 class="page-title">{{主标题，可用 <br> 断行}}</h1>
      <div class="title-bar"></div>
      <div class="quote-card">{{金句，关键词用 <b> 包起来自动高亮}}</div>
      <p style="font-size:21px;line-height:1.9;max-width:640px">{{正文 1–2 句}}</p>
    </div>
  </div>
</section>
```

## 四、图槽位

| 槽位 | 必填? | 模式 | 比例 | 构图要求 |
|------|-------|------|------|----------|
| `pXX_hero` | ✅ 必填 | concept / case | 3:4 竖版 | 右侧 46% 全高**竖**构图；主体偏右（左边 1/4 会被渐变吃掉），远景/氛围为主 |

**禁用**：信息图、图表、密集文字截图（46% 宽里看不清，而画面上它只是一块糊）。
图贴在 `.p5-visual` 的 `background-image` 上 —— `data-img-prompt` 要写在**同一个 div** 上，
只写 `background-size` 而没有 `background-image:url()` 的话这一格会被判成「贴不上」，画面从头到尾是占位图。

## 五、变体

| 编号 | 变化 | 用途 |
|------|------|------|
| V1 | 镜像（图在左）：给 `.p5-visual` 加 `style="left:0;right:auto"` | 连续两页 L1 时换气 |
| V2 | 去掉金句卡，正文提到 24px | 内容是叙述而非主张 |
| V3 | 金句卡换成 2–3 条 `.point-bar` | 主张能拆成并列的几条 |
| V4 | 图宽收到 38%（inline `width:38%`） | 文字实在放不下 |
| V5 | 加 `.corners` 角标 | 想要版面感 |

---

## 六、design 提示

- **视觉中等**：图只占 46% 且被渐变压过，可以连着放在数据页之后，不需要缓冲页
- **字号铁律**：`page-title` ≥ 48px，金句 ≥ 30px，正文 ≤ 21px —— 正文和金句字号拉不开的话，一页就有两个主角，翻起来像"这页写满了"
- **与 L20 的区别**：L20 是 30/70（文少图多）+ 三圆收尾，L1 是 54/46（文多图少）+ 金句主角
- **与 L3 的区别**：L3 是**案例**页（企业名 + 三条战绩），L1 是**观点**页（一句主张）
