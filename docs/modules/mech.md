# 机械积木课堂（/mech）

真 LDraw 零件摆出来的机构，只展示。位置、转角一律在 `mechParts.ts` / `mechCases.ts` 里算，
舞台（`MechStage.ts`）只照着摆。这里每一条出错时都**不报错**：齿轮照样转、页面读数照样是个数。

- **零件朝向全是实测的（`PARTS.axis`），加零件先用 LDrawLoader 量包围盒再写。** 量错的话轴横着穿过梁、
  齿条的孔朝错方向（齿条 6592 长度沿 X、孔是竖的），画面上是零件互相穿模而不是报错。
- **打包零件（`scripts/ldraw-pack.mjs`）在 zsh 里用变量传编号要写 `${=IDS}`。** 不拆开的话整串被当成
  一个编号，脚本先报找不到，但**输出文件已经被覆盖成只剩前一次的内容**，页面报「零件包里缺 …」。
  改零件表时顺手把脚本头上那行用法一起改（它就是当前包的完整清单）。
- **司机面朝 -z（车头），他的左手边是 +x。** 按屏幕左右起名的话「左前轮」标在右边的轮子上，
  而读数（内侧轮转得多）照样对，看不出贴反了。
- **齿轮齿条的阿克曼是扫出来的，不是「转向臂延长线交在后轴中点」。** 那条经验规则是给拉杆在主销前面、
  直接连两个臂的转向用的，套到齿条上误差十几度。齿条离主销 3 格、后轴 22 格是按两条轮轴线落在后轴上的
  距离扫的（要算上车轮相对主销往前那一格偏置）；改轮距 / 拉杆 / 齿条位置就得重扫，`TurnCenter` 会照实
  显示差多少毫米。
- **齿条行程受「拉杆够得着转向臂」限制（走到 17 左右就够不着）。** 舞台加载时拿 ±swing 核一遍并报错；
  不核的话越界那几帧转向节停在上一帧，看起来像卡了一下。
- **方向盘到小齿轮之间每咬合一次反一次向，所以减速那一级中间有个 8 齿惰轮。** 去掉它读数全对，
  只是方向盘往左打、车往右拐。
- **隔了几级齿轮之后，小齿轮回正时的转角不是 0（现在是 180°），齿条按「转角 - rest」走。**
  rest 还必须正好让一颗齿朝着齿条，`rackPinion` 会核；前面的齿轮挪一个位置就可能对不上，画面上是齿穿过齿。
- **页面上的「方向盘转几圈 → 齿条走多远」一律走 `rackTravel`（和舞台同一份 `shaftAngles`）。**
  万向节不等速，写成 swing × 齿数比 的话读数和画面差几度，而且每加一级齿轮就要改两处。
- **万向节按真的不等速关系算（tan θ从 = tan θ主 · cos β），十字轴每帧按两个叉口的朝向摆。**
  按「两边转一样多」摆的话转到 90° 时十字轴和叉口错开整整 β，看上去叉口脱开了。
  61903 在库里是两个叉口 + 十字轴拼死的，所以打包的是 62520 / 62519 两个子件。
- **汽车那种又扁又长的机构拆开用 `Placement.apart`（按层抬），不走 `explodePlan` 的沿 z 拉开。**
  转向节组里的零件的位移要按组当前的转角反转回去（`placeParts`），否则打着方向时点「拆开」轮子斜着飞。
- **底盘纵梁在 ±4 格，是因为方向盘半径 32。** 再往里方向盘穿过纵梁 —— 转向柱现在是斜着往上的，
  以后改平了要重新核这个。
