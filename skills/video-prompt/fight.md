## 附加规范 · 打斗动作

**写前对三大支柱，缺哪个补哪个**：节奏感（快、连、不拖）/ 镜头感（有压迫、有规模、看得懂谁占上风）/ 打击感（疼、实、有后果）。

**打击感三要素（每记有效命中必写）**：
1. 蓄力：重心下沉、拧腰到极限、眼神锁定对方；
2. 命中：接触瞬间停顿一帧 + 画面猛震一帧；
3. 后果：受力方反应（衣料压缩 / 上身偏斜 / 重心偏移 / 大步后退，重击四项全给）+ 环境反馈。
反应强度和打击力度成正比：轻击衣料微震，重踹飞退两大步。

**逐拍速度标注**：不要只在开头写一句"全程高速"。每个动作后面紧跟速度标签——出招写"高速 / 瞬发 / 快到拖出残影"，命中写"停顿一帧 / 时间凝滞一瞬"，对峙写"凝住半拍 / 目光锁定不动"，收势写"稳稳落定"。
慢是快的参照物：前摇慢 → 出招快 → 命中顿，比"全程都快"更有速度感。每 3–4 拍至少一次静（对峙、蓄力、落定），每次静不超过 0.3 秒。禁止只写"激烈 / 快速 / 猛烈"。

**景别轮切**：同一段打斗景别必须轮换：远景交代站位 → 中景攻防交换 → 近景发力与表情 → 特写接触点 → 拉回全景看后果。

**运镜语义**：推近 = 压迫、锁定，用在高速动作瞬间；拉远 = 破坏力、规模，用在命中落地瞬间；贴地仰拍上推 = 气势；平行跟拍 = 速度；俯拍下压 = 被压制。最有效的组合是"先推近看细节 → 命中瞬间拉远看后果"。

**镜头跟谁动**：每个时间段写明镜头主导权——"跟进攻方的动量"或"跟受力方的反馈"，一镜到底时明确写"一镜到底、不切镜"。

**动作写法**：每个动作写"起手 → 路线 → 落点 → 收式"。按"发力（进攻方）→ 反应（受力方 + 五官）→ 视觉反馈（环境）"三段写。
位移用大步推进、大步后退、大步踏出稳住，禁反复小碎步蹭动。
有具体拳种时先锁定拳种的运动逻辑（如太极圆弧借力、腰旋引带；咏春短促寸劲、直线进逼），两个角色的特征不混用。

**次级运动**：发力或急停之后，衣摆、发丝、软质配饰因惯性继续摆动、延迟归位，不能焊死在身上。

**破坏尺度与力度匹配**：普通命中只到道具级（杯子震跳、纸张掀起）；有效重击到家具级（凳子翻倒、桌面开裂）；决胜一击才到建筑级（地面放射状裂开、碎石四散），且必须配拉远或俯拍让人看见规模。同一处环境不重复破坏两次。

**看得出快的三个信号（至少给两个）**：残影（数量、位置、存续时长写清，如"残影 2 道、存续约 0.3 秒后消散"）/ 镜头跟不上（只剩残影轨迹）/ 环境拖拽（衣摆发丝被风压向后猛扯、沿途碎屑被卷起）。高速段中间也要有持续的环境粒子流动，不能只在命中点有特效。

**声音视觉化**：短视频常静音播放，"巨响 / 轰鸣"后面必须紧跟一个看得见的反应——重物砸地写"画面微震、地面尘粒离地浮起"；拳拳到肉写"接触点一圈透明冲击涟漪向外推开、衣料向四周炸开"；兵器交击写"接触点火花炸开"；木头断裂写"裂纹由接触点逐帧向外爬行、木屑扇形飞射"。同一拍只给一个信号；除二次元风格外不写"砰 / 啪"这类贴字。写实路线可以直接写真实音效（呼吸、脚步、衣料破风、拳掌碰撞），并写明无背景音乐。

**光与背景**：全片锁定一个主光方向，切镜时影子方向不能跳。背景人物只放在画面边缘做低强度动作，不看向打斗、不进入中央。
