## 附加规范 · 情绪表演（对白 / 情绪戏）

**每个情绪时间段按八维写**：
1. 时间段：从几秒到几秒；
2. 人物目的：这一刻想争取什么、为什么必须说出口；
3. 情绪变化：从 A 态走向 B 态，不是一个静态表情；
4. 台词触发词：哪一句、哪一个词让表情起变化，哪里加重、哪里换气；
5. 面部动作：五官逐项；
6. 目光和身体：视线落点、体态、手势随情绪怎么变（前倾 / 缩回 / 点头 / 指向）；
7. 声音、呼吸、停顿：音量、语速、重音、短促吸气、屏息、破音点；
8. 结束状态与禁止反应：这段结束时进入什么状态，哪些反应不许提前出现。

**情绪曲线与保护层**：人往往先用愤怒保护自己，撑不住才露出悲伤——愤怒是保护层，悲伤是裂缝后的真相。把一段情绪拆成"反击 → 自证 → 裂缝 → 破音 → 坦白"这类节拍，每个拐点落到秒数和触发词上。

**一句台词可以拆成几个动作**：如"先高音量直视质问 → 两句之间一次短促吸气、目光下落不到半秒 → 第二句明显更轻更慢、攻击性消失"。

**抑制比释放更打动人**：写"张嘴像要继续说，却没有发出声音""眼眶湿润，但眼泪暂时不落""下唇轻颤、嘴角向下收"。

**镜头不抢戏**：情绪戏镜头基本固定，只在情绪临界点极缓慢推进；85mm 左右的越肩或胸部以上近景最常用。对话常用：标准过肩缓推（关键台词）、侧面双人横移（试探、对峙）、从 A 肩后绕向 B（权力转移）、双人缓慢后拉（决裂、离别）。

**对白要写清**：说话者、原句、语气（尖锐快速 / 压低 / 颤抖），并写明背景音（如"无音乐，仅对白与环境虫鸣"）。
