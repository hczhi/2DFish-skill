## 附加规范 · 舞台表演（唱跳 / 走秀 / 典礼）

**灯光四层（每段必写）**：主光（塑造主体、定明暗）/ 轮廓光（勾边、把人和背景分开）/ 背景光（打亮或染色幕布、大屏）/ 效果光（光束、频闪、追光、扫光）。写清每层的方向、颜色和节奏。

| 舞台类型 | 灯光基调 |
|---|---|
| 小型驻唱 / Livehouse | 暖色主光 + 侧逆轮廓光 + 少量染色，亲和沉浸 |
| 大型唱跳舞台 | 强对比主光 + 频闪光束 + 撞色染色，炸裂高能 |
| 高级感走秀 | 冷调主光 + 干净轮廓光 + 暗背景，高级神秘 |
| 颁奖 / 典礼 | 暖金主光 + 柔光铺底，庄重荣耀 |

**调度**：写清台位与走位（定点 → 移动路线 → 队形变化，如一字排开 → 散开 → 聚拢）、从哪侧上下场、大屏内容和手持道具。

**舞台镜头**：主体特写用观众席前区慢推近；气势全景用摇臂高位俯拍摇下；跟主舞者用侧台轨道跟移；群像用后区横摇扫过；高光时刻用特写推近定格。切换按鼓点卡拍切。

**表演情绪同样拆五官**："投入地唱"写成"睑裂微闭、眉放松、嘴角自然微扬、肩随节奏起伏"。光束、频闪、大屏内容和手持麦也要每段写清位置与状态。
